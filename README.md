# 网易 ModSDK - 制裁盒子附加包

这是一个基于网易我的世界 ModSDK 制作的高仿“制裁盒子”模组，面向个人存档，非网络服。

## 玩法说明
1. 放置“魔法土块”，会变成制裁盒子并掉落岩浆桶与 32K 制裁之刃。
2. 使用岩浆桶即可触发全服制裁（闪电、清空方块、凋零等）。
